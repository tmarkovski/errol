## Errol 1.0.2

- **Errol shows up when you open it.** Launching Errol, or opening it again from Finder or Spotlight while it runs, now brings up the console. A launch at login still waits in the menu bar, and Minimize in the app menu, or Esc, puts the console away.
- **Stop always stops cleanly.** Pressing Stop ends a relay as stopped wherever it is, whether Errol is typing, copying, or waiting on an app, instead of sometimes reporting that it couldn't type into an app.
- **Quitting mid-relay puts your clipboard back.** Quit now waits a moment for the relay to wind down, so whatever you had copied is restored before Errol exits.
- **ChatGPT's Space icon.** If you've picked ChatGPT's Space icon for its Dock tile, Errol shows it too, as it already did the Codex icon, and draws either one at the size the Dock does.
- **Lighter on both apps.** While it waits for a reply, Errol reads each app's window once per check instead of four times, and the console no longer redraws on every check.
- **Fixed:**
  - A conversation or Claude Code session whose title mentions stopping no longer makes Errol think an app is still replying, which held every relay until the title changed.
  - In a Claude Code session, Errol could press a button in the transcript that mentioned sending, such as a code block's "Run in terminal and send output to Claude", instead of Claude's Send button.
  - Errol could copy the wrong thing as the reply: a Claude Code step whose summary mentioned copying, or a file open in ChatGPT's side panel. A file open there no longer reads as an unsent draft, either.
  - The microphone now turns off when dictation breaks off or ends by itself.
  - The transcript keeps following the newest line when several arrive close together.
  - Arranging windows brings forward the window it arranged, not another window of the same app.
  - The permission guide's panel docks on the screen that holds most of the System Settings window.
  - A rare crash when a relay ended while its log was still being written.
