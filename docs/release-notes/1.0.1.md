## Errol 1.0.1

- **Easier permission setup.** Open System Settings now opens the list Errol needs, Device Control and Data Access on macOS 27, and puts Errol's icon in a small panel under the Settings window for you to drag into the list. Errol notices the moment it's enabled.
- **Updates without interruptions.** From this version on, updates download in the background and install the next time Errol quits. When one is ready, an Update button appears beside the ··· menu, and a click restarts Errol into the new version. Nothing about an update happens while a relay is running.
- **What each side is set to.** The line under the prompt box now shows each app's mode, model, and effort. When an app has several windows open, click the line to choose one.
- **Liquid Glass buttons** in the console, and a softer shadow under the prompt box.
- **No more settings screen.** Appearance and color palette are in the menu-bar icon's menu and the ··· menu, and About Errol opens a small window with the version, the website, and the licenses of the code Errol includes.
- **Fixed:** macOS 27's "Ask Siri" tag no longer sits over the console's text fields.
