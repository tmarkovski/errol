The Converged Composer

Two explorations ran in parallel: the option studies in this directory (A, B, and the quick-type row of C) and the skin studies' Perch direction, alongside the composer that has since shipped in the wireframe skin. They agree on far more than they differ. This document merges them into one proposal and works the single open question — where the conversation shape lives — through in mockups.

The skeleton nobody disputes anymore: one composer is the command surface; a single primary action morphs with the run (Run → Pause → Send → Resume); run options are quiet configuration, not peers of Run; ending is demoted and deliberate; a finished run stays readable until New session clears it; steering begins by typing and holds the run at the next handoff, with precise copy about who is still finishing.

Shapes on the composer

Option C's move, wearing Perch's clothes. The quick row — Free chat, Brainstorm, Debate, More — sits as the composer's first line, styled as Perch chips with the selection inked in. Directly beneath it, the shape's instructions in a quiet mono band, with a pencil for a session-only edit. A hairline then closes the setup zone, giving the card an anatomy: the shape and its instructions above the line, your words below it, actions at the foot. The topic keeps the room; the options chip keeps the corner the skin studies gave it; the amber circle runs.

1 · Idle — pills and preview as the composer's first two lines (recommended)

The argument for this placement: the pills are input. Selecting Brainstorm changes the message that will be typed into the opener, so the control belongs on the surface that composes that message — while everything above the card stays observational. The hairline gives it the separation the shelf promises without the distance: the options are visibly a different zone from your text, but the card is still one object. And the anatomy survives the run — mid-run, the setup zone swaps for a one-line context row above the same hairline, so the card keeps its shape while nothing else moves. It is also the arrangement Option C already proved, so both explorations land on it without contortion.

Shapes on a shelf

The literal reading of "up top": the pill row leaves the card and becomes its own shelf between the instruments and the composer, with the preview hanging from it. The shape reads as a session mode — closer to a segmented control — and the composer card is pure input, the most chat-app version of the panel.

2 · Idle — pills as a shelf between instruments and composer

It reads beautifully idle, but the shelf has no good home once a run starts: either it collapses (the panel's height jumps twice per session) or it lingers as disabled chrome between the live instruments and the steer field. And it separates the instructions from the field they configure by a card boundary. Worth seeing; not the one I'd build.

Mid-run

The collapse that placement 1 buys: the pill row and preview fold into one context line above the same hairline, everything else stays put. The composer invites a direction — typing is steering, no button — and the primary circle is now Pause. End session moves to the ··· menu, per the option studies; Pause is the safety action a panicked hand should hit.

4 · Steering — precise copy about who is finishing; send rides the handoff

The shipped composer already behaves this way underneath — typing begins the steer and the hold, erasing cancels it, a hand-paused run stays paused after the note is sent. What the convergence adds is the copy discipline from the option studies ("Will pause after Claude finishes" instead of a bare "Paused") and the context line keeping the shape and options readable without their controls.

The wireframe wears it too

The convergence is placement and behavior, not palette. The same arrangement in today's production skin: pills as inked capsules, the preview in the well's mono voice, the options chip and the filled circle exactly where the wireframe composer already has them.

5 · The same layout in the wireframe idiom — a contained code change, not a redesign

Recommendation

Build placement 1: the pill row and instruction preview as the composer's first two lines, the options chip staying in the toolbar corner. Brainstorm does move up top, as suspected — but attached to the composer rather than floating above it, because the shape is part of the message, not part of the instruments. Free chat joins as the first-class default; the More menu owns the rest of the collection plus the two editing paths ("Customize for this session" via the pencil, "Manage conversation types…" to Settings).

In the wireframe skin this is a contained change to the composer card — the pill row replaces the toolbar's shape chip, the preview line is new, and everything underneath (typing-to-steer, the morphing primary, the run clock and New session) is already shipped. If Perch graduates from study to skin, it starts as a new panel style beside the wireframe and inherits the same layout.

From Option C
The quick row with Free chat first, the visible instruction preview beneath it, More as overflow into the full collection.
From Perch
The surface language — soft neutrals, chip styling, avatars and flight path, one amber primary that carries every state.
From the shipped composer
Typing-to-steer with the steer-owned pause, the morphing primary circle, run stats that persist until New session.
From Options A/B
Precise status copy over generic labels, End session demoted to the overflow menu, options as configuration that never competes with Run.

Still open, deliberately: whether the quick set is fixed or learns from use (start fixed); whether the preview expands inline or in a popover (start with two lines and a popover); and how much of the instrument head survives in Perch (the wireframe keeps its own).
