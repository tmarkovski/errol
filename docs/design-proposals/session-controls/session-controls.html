Stop, three weights

The same foot mid-run with Stop drawn three ways. All three keep Pause the only filled button. A is what shipped.

A · Outlined circle (shipped). The primary's own size, paper on the well with the chip edge — the same raised look the tab thumb and the old New session capsule had. Reads as Pause's unfilled twin: same shape, same size, the fill alone telling them apart. (First drawn a size smaller; equal size won on the second look.)

Note queued · goes to Claude with the next handoffClear note

For: a button that looks like a button, at a glance distinct from the option chips. Against: one more outlined shape on the card.

B · Bare glyph. The option chips' family: nothing at rest but the glyph in a 32pt square, the hover wash when the pointer rests on it.

Note queued · goes to Claude with the next handoffClear note

For: the quietest; it borrows the chips' idiom exactly. Against: the chips are toggles, and a glyph in that idiom next to Pause can read as an option rather than an action — and a bare square glyph is easy to miss when the end is wanted in a hurry.

C · Word capsule. "End", 24pt tall, the capsule the old New session button wore.

End

For: says what it does with no tooltip. Against: the word is heavier than the glyph beside it, so the eye lands on End before Pause; and a word capsule at the foot competes with Clear note, which is also a word there.
