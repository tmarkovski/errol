# Design Proposals

Durable records of UI directions that may inform production work but are not
part of the application build.

- [Floating conversation widget](widget/README.md) — saved layout and control
  concepts, the selected capsule direction, and icon-only running controls.

- [Chat composer redesign](chat-composer/README.md) — three interactive proposals,
  a reconciliation direction, and a converged proposal for conversation setup,
  run controls, steering, and the wireframe instrument language.
- [Landing page for errol.chat](landing-page/README.md) — converged one-page concept: a
  live scripted relay as the hero, the conversation shapes, the naming session
  as proof, the wrong-window story, and a plain permission section.
- [Steering mid-run](steering/the-note-stays-put.md) — the converged design for
  steering notes and, at its end, the revisions built after trying it (the
  field is closed while the agents work; Pause opens it, Return sends and
  closes it), with [the problem framing](steering/the-note-in-flight.md) it
  answers. Since September 8 the pause stays at the foot's corner instead of
  standing in the field — see the session controls below.
- [Session controls at the foot](session-controls/README.md) — Run turning into
  Pause in place, an outlined Stop beside it, the don't-type notice in the closed
  field, and the finished run's summary with one New session button; three
  weights tried for Stop.
- [Focus coordination while steering](steering/focus-coordination.md) — two
  operation gates under the relay's existing control lock, so copying and
  delivery wait until the steering editor releases focus.
