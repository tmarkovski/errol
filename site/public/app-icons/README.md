# Demo app icons

These 256 px PNGs were extracted from the icons in the installed macOS app
bundles on September 5, 2026, preserving their original colors and artwork:

- `chatgpt.png`: `/Applications/ChatGPT.app/Contents/Resources/electron.icns`
- `claude.png`: `/Applications/Claude.app/Contents/Resources/electron.icns`

The icons identify the simulated ChatGPT and Claude windows and their
participants in Errol. They replace the previous generic chat and sparkle icons.
